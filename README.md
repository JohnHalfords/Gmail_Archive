# Gmail_Archive
PowerShell Archive Gmail emails labeled with a specific label
---
Produces a html log with filters
Highly commented
---
In the first line of the PowerShell script you can change a lot of settings: <br>
A few examples are: <br>
ArchiveRoot : The folder where the html files and attachements go (your Archive) <br>
ScriptFolder: The folder where this script (and its tokens) are <br>
TriggerLabel: The label you use in Gmail <br>
<br><br>
Several settings for:<br>
- filenaming convention
- testing
- logging
<br>
