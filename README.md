# Gmail_Archive
PowerShell Archive Gmail emails labeled with a specific label

Produces a html log with filters
Highly commented

In the first line of the PowerShell script you can change a lot of settings: 
A few examples are: 
ArchiveRoot : The folder where the html files and attachements go (your Archive) 
ScriptFolder: The folder where this script (and its tokens) are 
TriggerLabel: The label you use in Gmail 
  
Several settings for:
- filenaming convention
- testing
- logging
